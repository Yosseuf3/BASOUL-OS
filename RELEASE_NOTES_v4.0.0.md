# BASOUL v4.0.0

First stable BASOUL 4.0 release, promoted from the field-verified Beta 2 and RC2 baselines without feature expansion.

## Stable basis

- Beta 2 selected tester campaign completed successfully.
- BASOUL v4.0.0-rc.2 validated on Production.
- No open Blocker or Critical issues at stable release entry.
- Arabic / English switching and RTL / LTR behavior verified in field testing.
- Finance long-form mobile modal scrolling verified on iPhone Safari.
- Organization Administration navigation remains visible only to Owner/Admin and constrained by existing RBAC/RLS authority.
- Web and mobile Quality Gates passed on the release line.

## Included platform baseline

- Approved BASOUL Brand Foundation with original Symbol and Wordmark assets.
- Canonical YVL mechanics with BASOUL semantic adapter boundaries.
- Executive Dashboard and product surfaces for Projects, Tasks, Clients, Content, Knowledge, Finance, Activity, Notifications and Search.
- Email + Password authentication path.
- Owner / Admin / Member / Viewer administration boundaries.
- Responsive web behavior and bilingual UI foundation.
- Security-patched dependency baseline including nanoid 3.3.18.

## External mobile distribution status

- Android EAS cloud builds remain subject to the current monthly free-plan quota.
- iOS physical-device/internal distribution still requires suitable signing credentials and an active Apple Developer Program team.
- Existing bundle/package/EAS identifiers are preserved.

## Safety boundary

This stable release does not rename repositories, mutate Supabase Production schema/RLS/Auth, change domains, package/bundle/signing identifiers, or make billing decisions.
