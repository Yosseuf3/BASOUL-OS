# YVL changelog

## v1.0.0-foundation

- Established YVL principles, governance, token taxonomy, branding, iconography, patterns, HUD, illustration, social, UI, motion, and asset rules.
- Added canonical color, typography, spacing, radii, shadow, and motion token files.
- Added Draft 2020-12 schemas with canonical schema references.
- Added deterministic CSS, TypeScript/React, and React Native/Expo artifact generation.
- Added a static review-only showcase with stable visual-regression selectors.
- Added approval, accessibility, RTL, reduced-motion, rollback, and product-isolation requirements.

No product adoption, runtime style migration, font installation, rebrand, or production behavior change is included.
