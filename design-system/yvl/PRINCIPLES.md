# Principles

1. **Consistent** — the same meaning produces the same visual treatment.
2. **Recognizable** — restrained signature motifs build YOSSEUF recognition.
3. **Systemic** — tokens and rules precede isolated compositions.
4. **Scalable** — primitives support every product, platform, and density.
5. **Accessible** — contrast, focus, motion preferences, and legibility are requirements.
6. **Built for impact** — hierarchy and clarity concentrate attention on outcomes.
