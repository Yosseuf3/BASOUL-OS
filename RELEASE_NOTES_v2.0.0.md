# YOSSEUF OS v2.0.0 — Executive Operating System

## Added
- Executive Kernel orchestration layer.
- Explainable Decision Engine.
- Weighted Workspace Health Engine.
- Predictive risk analysis for seven- and fourteen-day horizons.
- Mobile Command Center combining decisions, health factors, and future risks.
- Engine output kept outside React components.

## Architecture
Presentation → Executive Kernel → Decision / Health / Predictive Engines → Domain Data.

## Compatibility
This is an overlay upgrade for the current v1.7.0 mobile codebase and preserves the existing dashboard navigation contract by using the `intelligence` route.
