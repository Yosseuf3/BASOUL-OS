# BASOUL Brand Foundation v1.0

This directory stores the approved, locked BASOUL visual foundation as a non-production brand candidate. The supplied visual reference is the source of truth. Nothing in this directory changes the YOSSEUF--OS product name, runtime branding, behavior, deployment, or production configuration.

## Directory map

- `foundation/` — the original supplied package README.
- `assets/primary-logo/` — approved primary-logo raster masters.
- `assets/symbol/` — approved symbol raster masters.
- `assets/wordmark/` — approved wordmark raster masters.
- `assets/app-icons/` — approved app-icon raster exports.
- `assets/product-lockups/` — approved product-family raster lockups.
- `reference/` — approved product-family visual reference.
- `specs/` — the supplied manifest and generated byte/dimension verification manifest.

## Locked asset rule

Do not regenerate, redraw, reinterpret, recolor, rename, or otherwise alter the supplied BASOUL visual assets. Preserve the supplied files byte-for-byte. Existing YVL assets remain independent and unchanged.

The current logo masters are raster-derived from the approved visual reference. Do not vectorize them automatically. Native SVG/vector reconstruction is a separate future task and requires visual verification before approval.

See `BRAND_STATUS.md` for approval state and `MIGRATION_BOUNDARY.md` for the production boundary.
