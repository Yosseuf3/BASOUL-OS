# BASOUL Migration Boundary

This foundation is documentation and approved source artwork only. It does not authorize a product, repository, application, package, domain, deployment, environment, database, or production-brand rename.

Production must remain YOSSEUF. Production renaming is explicitly prohibited until a separate BASOUL migration plan is written, reviewed, and approved through its own authorization process.

Until that approval exists:

- do not replace or redirect existing production branding;
- do not change runtime behavior, application metadata, manifests, package names, domains, or environment variables;
- do not modify Supabase, Auth, RLS, APIs, database schema, deployment configuration, or business logic;
- do not replace, edit, or remove existing YVL assets;
- do not automatically vectorize or reconstruct the raster-derived BASOUL masters.

Native SVG/vector reconstruction is a separate future task requiring exact comparison with the approved visual reference and explicit visual approval before any reconstructed asset may be treated as a master.
