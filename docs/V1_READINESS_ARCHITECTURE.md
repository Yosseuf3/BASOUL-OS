# YOSSEUF OS — v1 Readiness Architecture

## هدف v0.9.5

تثبيت نسخة الويب قبل تجميد الميزات، مع فصل تحميل مساحة العمل عن مكونات React وتجهيز حدود واضحة يمكن لتطبيق iOS استهلاكها لاحقًا.

## ما تم اعتماده

- `workspace-service.ts` نقطة موحدة لتحميل بيانات مساحة العمل.
- التحميل الجزئي: فشل وحدة لا يمنع ظهور الوحدات الأخرى.
- حالة مزامنة واضحة مع إعادة المحاولة.
- Error Boundary على مستوى التطبيق.
- منطق القرار يبقى داخل `core/intelligence` وليس داخل الواجهة.
- لا إعادة هيكلة Monorepo قبل v1.0 لتجنب مخاطرة غير ضرورية.

## بوابة v1.0 RC

1. نجاح `npm install` و`npm run build` محليًا.
2. اختبار CRUD لكل الوحدات.
3. اختبار RLS بحسابين مختلفين.
4. اختبار RTL والشاشات من 320px حتى سطح المكتب.
5. اختبار حالات بطء الشبكة والانقطاع الجزئي.
6. عدم إضافة ميزات جديدة بعد اجتياز البوابة.

## جاهزية iOS

تطبيق iOS سيستخدم لاحقًا نفس العقود الموجودة في `lib/types` وخدمات البيانات وطبقة Intelligence. الخطوة التالية بعد v1.0 هي استخراج الحزم المشتركة دون تغيير سلوك المنتج.
