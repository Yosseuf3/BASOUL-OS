# BASOUL OS — Vision 2030

## Why we are building it
BASOUL OS is an Engineering Business Operating System. It is designed to help engineering offices run projects, clients, finances, knowledge and decisions from one coherent workspace.

## Mission
Enable engineering offices to spend less time coordinating fragmented tools and more time delivering accurate, profitable work.

## Target users
- Small and medium engineering offices.
- Independent architects and engineering consultants.
- Project and operations managers.
- Future site and design teams using web and mobile clients.

## Differentiation
BASOUL OS is decision-first, engineering-aware and designed around role-based workspaces rather than a generic list of modules.

## 3–5 year direction
1. A stable web operating system for engineering offices.
2. Shared platform services and reusable decision engines.
3. Native iOS and Android field experiences.
4. Engineering workflows for drawings, BIM, RFIs, submittals, BOQ and site visits.
5. An assistive intelligence layer that recommends, summarizes and acts only with user control.

## Non-negotiable principles
- Simplicity before feature volume.
- Decisions before dashboards.
- User ownership and privacy before telemetry.
- AI assists; the user remains accountable.
- Every feature must save time, reduce errors or improve decisions.
- Documentation is part of the product.
