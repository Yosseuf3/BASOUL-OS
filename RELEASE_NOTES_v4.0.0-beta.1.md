# BASOUL v4.0.0-beta.1

First official BASOUL Beta release after the ecosystem visual unification, security hardening, legacy retirement, and Production launch.

## Highlights

- BASOUL visual identity unified across the primary product surfaces.
- Approved BASOUL Symbol and Wordmark preserved as canonical source assets.
- Email + Password is the primary development and production login path.
- Legacy root Magic Link / OTP implementation removed from the active Web runtime.
- Mobile login aligned to Email + Password while recovery and deep-link support remain preserved.
- BASOUL semantic adapter remains separated from canonical YVL mechanics.
- Legacy OS V1 retired and archived after evidence-based capability review.
- Legacy AI Core retired and archived after useful patterns were extracted.
- Copyright ownership standardized to ELSHENAWY RADWAN.
- BASOUL Beta Production deployment verified on Vercel.

## Production verification

- Vercel deployment target: `production`.
- `/`, `/login`, and `/forgot-password` verified with HTTP 200 responses.

## Product architecture

- BASOUL OS remains the primary operational/runtime product.
- BASOUL HQ remains the canonical governance authority.
- BASOUL PMO remains the execution/control layer.
- BASOUL AI · R1 remains the intelligent interaction/runtime product.
- BASOUL LABS · R2 remains an isolated research laboratory.
- Design System / YVL remain mechanics-only authorities beneath the BASOUL Brand Foundation.

## Known external constraints

- Cloud mobile build quotas and signing credentials remain external release constraints.
