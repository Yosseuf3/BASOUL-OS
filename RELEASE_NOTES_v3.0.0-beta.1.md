# YOSSEUF OS v3.0.0-beta.1

This is the first Beta release of Project Phoenix.

It combines the Executive Decision Dashboard, architectural drawing analysis,
interactive plan overlays, spatial findings, review comments, and the Expo field
review workflow on a production-hardened web foundation.

Beta 1 freezes the feature set while real-world acceptance testing is completed.
Only stability, security, performance, and release-blocking fixes should be
merged before the stable release.
