# YOSSEUF OS v1.1.0 — Project Workspace Foundation

## Highlights
- New project workspace opened directly from project cards.
- Live project KPIs for tasks, overdue work, execution progress, and net finance.
- Unified overview with client, area, dates, progress, and project task stream.
- Direct actions to edit the project or create a task.
- Responsive project workspace for desktop and mobile.

## Database
No migration is required for this release. The workspace uses the existing projects, tasks, clients, and finance tables.
