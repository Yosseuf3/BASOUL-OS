# YOSSEUF OS v2.2.0 — Cognitive & Architectural Foundation

This release begins implementation of the approved YOSSEUF Cognitive Core and Architectural Intelligence architecture.

## Added
- `@yosseuf/cognitive-core`
- typed cognitive stages and envelopes
- Engineering Confidence Engine
- modular cognitive pipeline
- `@yosseuf/architectural-intelligence`
- drawing, finding, evidence, location, and report contracts
- initial review-session report generator
- database migration 011 for drawings, reviews, and findings
- System Architecture Specification
- Founding Principles
- Architectural Intelligence Roadmap

## Scope honesty
This release is the foundation layer. It does not yet perform production-grade computer vision, DWG/IFC parsing, or official regulatory approval.
